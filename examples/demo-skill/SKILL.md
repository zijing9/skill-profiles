# 示例技能

这个文件就是技能的「说明书」。DSH 之类的工具只认两样东西：**目录名**和这个 `SKILL.md`。

## 结构

```
demo-skill/
└── SKILL.md          ← 必须有
```

可以放更多文件（脚本、模板、参考资料），它们都会跟着技能一起被复制和挂载。

## frontmatter 三个字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `name` | 是 | 技能标识，小写字母、数字、连字符；一般与目录名一致 |
| `name_zh` | 否 | 中文显示名，界面上优先显示它 |
| `description` | 是 | 什么时候该用这个技能。写清触发场景，不要写成功能列表 |

## 正文写什么

给「已经决定用这个技能的人」看的内容：

- 做这件事的步骤
- 关键参数、命令、路径
- 容易踩的坑
- 一两个可复制的例子

不需要重复 frontmatter 里已经说过的「什么时候用」。

## 怎么用这份示例

复制整个目录，改掉 `name` 和 `description`，重写正文，就是一个新技能。

用界面的话，直接点「新建」会生成一个更干净的骨架。
